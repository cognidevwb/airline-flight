# airline-flight

Aircraft, airports, flights and seats in SQL Server, with a Mongo read model. Schedules a flight, reserves a seat and answers the booking service over gRPC. Unit, integration, contract and end-to-end tests.

Part of the **airline-estate** estate: [meysamhadeli/booking-microservices](https://github.com/meysamhadeli/booking-microservices) `1182f4d`, split into 7 repositories. Clone them all into one folder; project references point at sibling folders.

## Depends on

- airline-platform (building blocks, service defaults)
